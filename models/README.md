# Models Directory

This directory stores trained models, vector indexes, and caches. **All contents are git-ignored** — they are regenerated from scripts.

## Contents (git-ignored)

| File/Directory | Size | Generated By | Description |
|---|---|---|---|
| `cache_tfidf_top50.pkl` | ~7.7 MB | `scripts/03_generate_cache.py` | TF-IDF top-50 candidates for 500 dev news |
| `vector_store/` | ~2-5 GB | `scripts/01_build_vector_store.py` | FAISS indexes for 3 neural encoders |
| `tfidf_model/` | ~50 MB | `scripts/02_build_tfidf_model.py` | Fitted TF-IDF vectorizer + IDF weights |

## Regeneration

```bash
# 1. Build TF-IDF model (fits on 315k process corpus)
python scripts/02_build_tfidf_model.py

# 2. Build FAISS vector stores for neural encoders
python scripts/01_build_vector_store.py

# 3. Generate TF-IDF candidate caches
python scripts/03_generate_cache.py        # dev set
python scripts/03_generate_cache_test.py   # test set
```

## Requirements

- `data/public_procurement_315k.csv` must exist (see `data/README.md`)
- For neural indexes: GPU with 48 GB VRAM recommended (RTX A6000 used in paper)
- CPU-only FAISS works but slower

## Paper Configuration

| Component | Details |
|---|---|
| TF-IDF | Unigrams, L2 norm, sublinear_tf=False, full vocabulary |
| Neural encoders | bert-base-portuguese-cased, BERTimbau Large, HeIBERT |
| Index type | FAISS FlatIP (inner product on normalized vectors) |
| Candidates per query | 50 (post-SQL filter) |

## Note on data leakage prevention

TF-IDF IDF weights are computed **exclusively on the 315,052 official processes**, never on the news queries. The scripts enforce this by fitting the vectorizer on the process corpus only.
