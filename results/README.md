# Results Directory

This directory stores execution outputs: logs, checkpoints, metrics JSONs. **All contents are git-ignored** — they are regenerated by running the pipelines.

## Contents (git-ignored)

| Pattern | Description |
|---|---|
| `*.log` | Verbose pipeline logs |
| `checkpoint_*.json` | Pipeline resumable checkpoints |
| `single_call_*.json` | Single-call reranking results |
| `tournament*.json` | Tournament reranking results |
| `all_methods_*.json` | 13-method retrieval consolidation |
| `consolidado_*.json` | Final recall tables |
| `ngrams_*.json` | N-gram retrieval details |
| `retrieval_*.json` | Retrieval per-method details |
| `errors_analysis.json` | Error analysis |
| `*_metrics_summary.md` | Human-readable summaries |

## Regenerating results

```bash
# Full pipeline (dev)
make dev

# Full pipeline (test)
make test

# Retrieval evaluation only
make eval-retrieval

# Reranking only
make rerank
```

See `Makefile` for exact commands.

## Paper tables location

Final formatted tables for the paper are in:
- `paper/reviewers/sbc_template/sbc.tex` (LaTeX tables)
- `documentacao/TABELA_FINAL_ARTIGO_TODOS_RECALLS.md` (Markdown)
- `documentacao/RESULTADOS_FINAIS_500_NOTICIAS.md` (Detailed report)

## Latency note

The paper reports latencies measured on specific hardware:
- **AMD EPYC 9654** (1.5 TB RAM)
- **NVIDIA RTX A6000** (48 GB VRAM, CUDA 12.8)

Latencies on different hardware will vary. The 20B model fits entirely in VRAM on A6000; CPU offload will significantly increase latency.
